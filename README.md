Направленные графы
Это графы, где связи между точками (вершинами) имеют направление (стрелки). Путь возможен только от одной точки к другой, но не обязательно обратно.

Задачи:

Построение маршрутов с односторонним движением (навигаторы, дорожные сети).
Анализ зависимостей (какие пакеты нужно установить перед программой, в каком порядке собирать задачи).
Определение влияния в соцсетях (кто на кого подписан).
Проверка достижимости (можно ли добраться из пункта А в пункт Б).
Планирование этапов (топологическая сортировка), чтобы соблюсти последовательность действий.

Веса графов 
Это числовые значения (стоимость, расстояние, время), приписанные связям между точками. Граф может быть как направленным, так и нет.

Задачи:

Поиск кратчайшего или самого дешевого пути (GPS-навигаторы, логистика).
Оптимизация затрат на прокладку сетей (минимальное остовное дерево — где поставить вышки связи или столбы ЛЭП с минимальным расходом кабеля).
Максимальный поток (сколько машин или данных может пропустить сеть в единицу времени).
Оптимизация ресурсов и логистики (задача коммивояжера).

Git 
Система контроля версий, которая внутри устроена как ориентированный ациклический граф (DAG). Каждая вершина — это снимок состояния проекта, а стрелки указывают на предыдущие снимки (родителей).

Задачи:

Сохранение истории проекта и мгновенный откат к любой прошлой версии.
Параллельная работа нескольких человек без потери чужих изменений.
Слияние разных версий кода в одну.
Работа в офлайн-режиме (у каждого есть полная копия истории).

Коммит (Commit) 
Снимок (snapshot) состояния всех файлов проекта в конкретный момент. Содержит: уникальный идентификатор (хеш), указатели на предыдущие коммиты (родителей), 
ссылку на полное дерево файлов и данные об авторе. Если файл не менялся, Git не копирует его заново, а просто ставит ссылку на старую версию.

Ветка (Branch) 
Это просто подвижный указатель на один из коммитов. Ветка не хранит копии файлов. Когда вы сохраняете новый коммит, указатель ветки просто перескакивает на него вперед.
 Если от одного коммита отходят две ветки, граф начинает ветвиться, и у снимка появляются «дети» в разных направлениях разработки.
 Главная ветка (обычно main) — это такой же указатель, просто выбранный в качестве основного.
